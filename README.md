# learning-lab 🧪

A personal **learning-first engineering lab** built using **C# and .NET**.

This repository is not a single project or framework.  
It is a **long-term workspace** for learning, experimenting, documenting, and revisiting core software engineering concepts over time.

Think of it as:
- A **knowledge base**
- A **practice ground**
- A **living reference repo** that evolves with experience

---

## 🎯 Purpose & Philosophy

This repo exists to support **deep understanding**, not rushed implementation.

Core principles:
- Learning > speed
- Clarity > cleverness
- Growth over time > one-off demos
- Experiments are welcome, but **core code stays clean**

This is intentionally **not production code** — but it *is* professional-quality learning code.

---

## 🧠 Learning Areas Covered

### 1. Algorithms & Problem Solving
- LeetCode-style problems solved in **C#**
- Organized by topic:
  - Arrays
  - Strings
  - Trees
  - Graphs
  - Dynamic Programming
- Focus on:
  - Readability
  - Reusability
  - Clear reasoning over micro-optimizations

### 2. Design Patterns
Full coverage of:
- Creational patterns
- Structural patterns
- Behavioral patterns

Each pattern includes:
- Dedicated folder
- Clean example implementation

- Notes explaining *why* the pattern exists, not just *how* to code it

### 3. AI / Machine Learning (in .NET)
Learning and experimentation using the .NET ecosystem:

  - Prompting
